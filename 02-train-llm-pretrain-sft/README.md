# Training LLM: Pretrain + SFT

End-to-end pipeline обучения языковой модели в двух частях:

1. **Pretrain с нуля** — обучение собственного decoder-only трансформера
   (~150M параметров, LlamaConfig) на корпусе русской классической литературы.
   Цель — научить модель структуре языка: связной грамматике, пунктуации,
   стилистике русской прозы.
2. **SFT (Supervised Fine-Tuning)** — дообучение предобученной Qwen2.5-0.5B
   на русскоязычном инструктивном датасете для перехода от base-модели к
   формату «вопрос → структурированный ответ».

Проект показывает обе типичные стадии обучения LLM (pretrain и post-train) на
упрощённом, но методически корректном масштабе.

---

## Часть 1. Pretrain собственного трансформера

### Данные

[**RussianNovels**](https://github.com/JoannaBy/RussianNovels) — корпус
произведений русской классической литературы (Толстой, Достоевский, Гоголь,
Чехов и др.).

**Препроцессинг:**
- удаление дубликатов;
- фильтрация предложений, содержащих не-кириллические буквы;
- нормализация повторяющейся пунктуации;
- разбиение на чанки по синтаксически связанным группам предложений с
  добавлением `<bos>` и `<eos>` токенов.

### Токенизатор

**Кастомный BPE-токенизатор** размером ~3K токенов, обученный с нуля на
корпусе RussianNovels. Малый размер словаря оправдан узким доменом —
универсальные токенизаторы (vocab 30K+) для одного корпуса избыточны и
неэффективны.

### Модель

**Decoder-only Llama-style трансформер**, инициализированный с нуля:

| Параметр | Значение |
|---|---|
| Архитектура | LlamaConfig (decoder-only) |
| `hidden_size` | 1024 |
| `intermediate_size` | 1536 |
| `num_hidden_layers` | 16 |
| `num_attention_heads` | 16 |
| `num_key_value_heads` | 8 (GQA) |
| Параметров | ~150M |
| Длина контекста | 512 токенов |
| Vocab size | ~3K (кастомный BPE) |

### Обучение

| | |
|---|---|
| Optimizer | AdamW |
| Эпох | 5 |
| Шагов | 2085 |
| Batch size (effective) | 64 |
| Train loss (final) | 3.43 |
| Время обучения | ~20 минут |
| Precision | bf16 |

В процессе обучения настроен callback, который каждые 500 шагов генерирует
ответы на тестовый набор промптов — это позволяет наглядно отслеживать, как
модель постепенно учится связности и стилю.

### Результат

После 5 эпох модель **уверенно генерирует синтаксически связный русский
текст в стиле русской классики** — корректная грамматика, правильное
согласование, узнаваемые стилистические маркеры (диалоги через тире, имена и
обращения характерные для классической прозы).

Пример генерации:

> **Промпт:** «Сила войска зависит от его духа»
>
> **Модель:** «Сила войска зависит от его духа. — сказал он, хмуря брови.
> — Милый мой! Угрюмая, грязноватая ночь медленно проходила мимо нее и не
> шевелилась на ее лице; потом она вспомнила о своей жизни, о своем
> счастье…»

Содержательной осмысленности от модели такого размера, обученной с нуля на
~10 МБ текста, ожидать не следует — но **структуру языка она усвоила**, и
именно эта цель ставилась.

## Часть 2. SFT дообучение Qwen2.5-0.5B

### Данные

[**d0rj/alpaca-cleaned-ru**](https://huggingface.co/datasets/d0rj/alpaca-cleaned-ru) —
очищенный русскоязычный перевод инструктивного датасета Alpaca. Формат
конвертирован в диалоговую структуру:

```
input       →  system
instruction →  user
output      →  assistant
```

### Базовая модель

[`Qwen/Qwen2.5-0.5B`](https://huggingface.co/Qwen/Qwen2.5-0.5B) — base-вариант
(не chat / instruct). Без дообучения модель умеет продолжать текст, но не
держит инструктивный формат: на вопросы отвечает мусором, скатывается в
обрывки разноязычных фрагментов.

### Обучение

| | |
|---|---|
| Optimizer | AdamW |
| Эпох | 1 |
| Шагов | 625 |
| Batch size (effective) | 16 |
| Learning rate | 2e-5 |
| Weight decay | 0.01 |
| Warmup | 10% |
| Train loss (final) | 1.49 |
| Precision | bf16 |

### Результат: «до vs после» SFT

Сравнение генераций на одних и тех же промптах:

**Промпт:** «сколько планет в нашей солнечной системе?»

| | Ответ |
|---|---|
| **До SFT** | «Всего две: Земля и Марс. Земля — это планета, которая находится в центре нашей системы. Она является самым крупным и крепким планетой в нашей вселенной…» |
| **После SFT** | «На нашей солнечной системе существует 8 планет, среди которых: 1. Земля 2. Марс (малая планета) 3. Сатурн 4. Уран 5. Юпитер…» |

**Промпт:** «когда собирать крыжовник?»

| | Ответ |
|---|---|
| **До SFT** | «- Книги - Новости - ОБЩЕСТВО - Новости Омска - Телеканал Омск-Россия - Краснодарский край - Омский край…» (мусор) |
| **После SFT** | «Собирая крохотные крыжовники, обычно это занимает не более 30 минут. Взяться за их изготовление можно в течение нескольких часов до сбора. Это зависит от размера и количества крыжовников…» |

**Что модель усвоила:**
- структуру инструктивного ответа (вступление → пункты → вывод);
- удержание языка генерации (ответы стабильно на русском);
- приближенно-релевантную фактуру (правильное число планет, тематические
  слова к вопросу).

**Что осталось:**
- фактические ошибки сохраняются (это ожидаемо — SFT учит формату,
  не знаниям; за факты отвечает pretrain, который у Qwen 0.5B сам по себе
  ограничен);
- иногда вкрапления английских слов и галлюцинации.

Качество соответствует ожидаемому для модели на 0.5B параметров после
короткого SFT — задача показать, что именно SFT даёт переход от
«продолжателя текста» к «отвечающей на инструкции» модели.

## Возможные улучшения

- **Pretrain на бо́льшем корпусе** — добавить русскую википедию, новости, чтобы
  модель училась не только литературному стилю.
- **Increased context length** — 1024+ токенов с RoPE-расширением для
  длинных контекстов.
- **DPO / RLHF поверх SFT** — следующий этап post-train для выравнивания
  ответов с предпочтениями пользователя.
- **Eval-набор с метриками** — добавить количественные метрики качества
  генерации (perplexity на held-out, ROUGE/BLEU на инструктивном тесте,
  LLM-as-judge на адекватность).
- **LoRA / QLoRA** для SFT вместо полного fine-tuning — экономия памяти и
  возможность обучать модели большего размера.
